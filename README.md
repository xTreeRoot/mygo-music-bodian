# 波点音乐插件 · MB / MyGo

**0.3.4**，同一份纯 JavaScript 插件用于 MB 桌面、iOS 和 Android。最低宿主兼容版本为 **MyGo 0.1.17**；移动端需使用支持 JavaScript 插件的 MB。直接访问波点 / 酷我服务，无需 Node 后台、独立 API 服务或外部播放器。

由 xTreeRoot 基于 [amqsy/mygo-music-bodian 0.3.3](https://github.com/amqsy/mygo-music-bodian) 继续维护，保留上游历史及 MIT 许可证。来源见 [NOTICE.md](NOTICE.md)。

## 安装

在 MB「设置 → 插件」中选择从 GitHub 安装，输入：

```text
xTreeRoot/mygo-music-bodian
```

或从 [最新 Release](https://github.com/xTreeRoot/mygo-music-bodian/releases/latest) 下载 `plugin.zip` 导入。三端使用同一个 ZIP，不需要解压或安装依赖。按宿主提示允许清单中的 API、封面及音频域名。

插件 ID 为 `bodian`，会与相同 ID 的上游插件共用安装位置。沿用原有 `session`、`devid` 和最近播放存储，覆盖前请确认来源。

## 登录与本地数据

点击登录，用**波点音乐官方 App** 扫描二维码并确认。手机上使用时可由另一台设备扫码，同机扫码取决于官方 App 是否支持相册识别。

取消登录会停止请求和轮询，迟到响应不会覆盖账号。退出只停用会话，保留凭据、设备 ID 和最近播放；再次登录先尝试签名验证旧凭据，仅在服务端返回一致的账号与凭据后恢复。公开昵称页不验证 token，不能用它认定登录成功。验证接口不支持或会话失效时会重新提供二维码；临时网络错误保留数据并报错。

会话和设备 ID 存在宿主 `host.storage` 管理的插件数据目录，属于本地明文数据，不使用系统钥匙串，不进入仓库或发行包。token 与设备 ID 关联，清除插件数据后需要重新扫码。

## 功能

- 搜索歌曲、歌手、专辑和歌单，支持搜索建议和分页。
- 首页推荐、每日推荐、排行榜、歌单广场与分类、话题、音乐日历。
- 电台、场景推荐、最近播放、听歌统计、个人歌单和喜欢的音乐。
- 保留上游歌单编辑、喜欢歌曲、收藏歌单 / 专辑、关注歌手及评论功能。
- 中文 LRC 歌词、标准 / 高 / 无损取流，返回服务端实际音质；补充媒体域名与请求头。

播放与收藏权限取决于账号权益及地区版权，只使用服务端实际返回的音源。插件设置「音质覆盖」可填写 `standard`、`high`、`lossless`，留空跟随播放器。

## 限制与验证范围

- 波点部分曲目匿名请求返回 20018 等权益限制，需要有权限的账号；不会绕过限制。
- 单张歌单最多读取 1000 首，收藏歌单最多列出 1000 张；歌手歌曲默认最多 100 首。
- 部分场景推荐会重复或耗尽，沿用上游的去重与已知列表轮播处理。
- 旧凭据验证接口的有效账号成功路径使用合成响应回归。匿名实际请求会被拒绝，尚未用真实有效账号验证该恢复路径；服务端不支持时重新扫码。

2026-11-21 验证：

- 103 项离线行为回归全部通过，覆盖搜索分页、歌单、评论、歌词、音质回退，以及三端取消、停用 / 验证复用和身份保护。
- 在桌面实际 MoeJS + Web APIs 及分别提取的 MB iOS / Android 实际 QuickJS + 宿主脚本中，运行同一份入口，检查搜索分页、中文歌词、音频结果、扫码流程和退出 / 重新登录。API 使用合成响应，没有操作用户应用。
- 匿名在线检查覆盖四类搜索、下一页、建议、首页、榜单及歌曲、公开歌单、专辑、歌手、歌词、评论和免费标准 MP3 实际字节；官方二维码仅准备后取消，没有授权账号。
- 尚未进行真实账号扫码、VIP 音质、线上歌单写入及三端真机播放验收。运行时检查不等同于真机验收。

## 开发与复现

`index.js` 是唯一运行入口，无需构建。ZIP 采用公开文件白名单。

```sh
npm run check
npm run test:live
python3 scripts/package.py
```

可选实际运行时检查（仅只读访问 MB；编译产物和合成账号放临时目录）：

```sh
MOEJS_HOST_DIR=/path/to/MB sh scripts/test-desktop-runtime.sh
python3 scripts/test-mobile-runtime.py --mb /path/to/MB
```

桌面检查需匹配 MB `go.mod` 的 Go 工具链；移动检查需 Python 3、Clang 及 MB 的 `ios` / `android` 引用。匿名在线检查仅在显式执行时访问服务，不在 CI 自动发起登录或修改音乐资源。
